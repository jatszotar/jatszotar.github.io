## Magyar

Kilenc oktató minijáték 5–10 éves gyerekeknek, böngészőben: számlálás,
memória, színsor, számsor, kisebb-nagyobb, matek, szorzótábla, óra és
szókirakó. A haladás, a téma és a hangbeállítás a böngészőben marad meg.

```bash
npm install
npm run dev      # fejlesztői szerver
npm run build    # éles build
npm test         # tesztek
```

## English

Nine educational mini-games for children aged 5–10, running in the browser:
counting, memory, colour sequence, number sequence, comparing, arithmetic,
times tables, clock and word building. Progress, theme and sound settings are
stored locally, in the browser only. The interface is in Hungarian.

```bash
npm install
npm run dev      # dev server
npm run build    # production build
npm test         # test suite
```

TypeScript + Vite + Vitest. Node 18+.
